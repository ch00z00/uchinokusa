# ロードマップ

MVP のあとのフェーズと、MVP のリリースに要る作業（tasks.md にないもの）のチェックリスト。README の進捗は、ここと `.kiro/specs/household-plant-care-mvp/tasks.md` のチェックボックスの数から計算する（`scripts/update-progress.mjs`）。期間は `docs/progress/schedule.json`。

- 各フェーズの項目は、見込みの粒度（2026-11-23 時点）。フェーズを始めるときに仕様（要件・設計・タスク）を作り、その `tasks.md` から数えるように `schedule.json` を切り替える
- 見出し（`## `）の名前は `schedule.json` の `section` と同じにする。変えるときは両方を変える
- MVP の対象外とした機能の出どころは `.kiro/steering/product.md` の「今後の構想」と、`requirements.md` の「MVPの対象外」
