# デザインの判断の記録

デザイン（見た目・操作感・デザインシステム・デザインから実装への引き継ぎ）で迷ったこと・決めたことを、1件1ファイルで残す。形式は `docs/decisions/`（設計・実装の判断）と同じ ADR とし、番号はこのディレクトリの中での連番とする。

- ファイル名：`NNNN-短い題名.md`（番号は連番）
- 参照するときは、`docs/decisions/` の番号と区別するため、パスごと書く（例：`docs/design/decisions/0001`）
- 状態：`提案` / `採用` / `廃止` / `置き換え（→ NNNN）`
- 一度採用した記録は書き換えず、判断が変わったら新しい記録を追加して、古い記録の状態を「置き換え」にする
- 採用した判断のうち、デザインや実装のたびに守るルールは `.kiro/steering/design.md` に反映する
