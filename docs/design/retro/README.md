# デザインの振り返りの記録

`/retro`（`.claude/skills/retro/SKILL.md`）で、デザインの作業の区切りごとに1ファイルずつ残す。ここから抜き出した好みは `docs/design/preferences.md` にまとめる。

## ファイルの名前
`YYYY-MM-DD-<主題>.md`（例：`2026-11-10-today-list.md`）。主題は、画面 ID（`docs/design/screen-inventory.md`）か部品の名前にする。

## 書き方
```markdown
# <日付> <対象の画面・部品>

## 試したこと
| 案 | 何を・なぜ | ユーザーの反応（引用） | 結果 |
|---|---|---|---|
| 1 | … | 「…」 | 却下 |
| 2 | … | 「…」 | 採用 |

## 決まった形
- …

## 抜き出した好み
- …（`preferences.md` に足した・回数を増やした）

## この画面だけの事情
- …（好みにはしない）
```
