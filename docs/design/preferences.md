# デザインの好み

ユーザーのデザインの好みの一覧。デザインの作業（Figma、画面・部品の見た目の実装）の前に読み、最初の案からこれに沿う。
`/retro`（`.claude/skills/retro/SKILL.md`）で、試行錯誤の記録（`docs/design/retro/`）から育てる。3回以上出てきた好みは、`.kiro/steering/design.md` に入れる案を出す。

## 書き方
- 1つの好みを1行にする：`- <好み>（<n>回）— 根拠：retro/<ファイル名>「<ユーザーの言葉>」`
- 食い違う好みが出たら、新しいほうにし、古いほうは「改めた」に移す（理由とともに残す）
