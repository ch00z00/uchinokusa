# 0013. 招待はトークンのハッシュだけを保存し、URL は作成時にだけ返す

- 状態：採用
- 日付：2026-11-03
- 関連：タスク 5.1、`server/internal/domain/invitation.go`、`server/internal/app/invitation.go`、要件3-1・3-7・20-3

## 決定
1. **トークンは `crypto/rand` の256ビットの乱数を base64url にしたもの（43文字）とし、DB には SHA-256 のハッシュだけを保存する**
   - DB の中身が漏れても、招待リンクを作れない
   - トークンは十分に長い乱数なので、パスワードと違い、ソルトや遅いハッシュ関数（bcrypt など）は要らない。探すときも、ハッシュの一致で引ける
2. **招待リンクの URL は、作成のレスポンスでだけ返す**
   - トークンを保存しないので、あとから URL を作り直せない。一覧には招待コードを出すので、あとから共有したい場合はコードを使うか、新しい招待を作る
3. **招待コードは、紛らわしい文字（0・O・1・I・L）を除いた31文字から、8文字を `crypto/rand.Int` で選ぶ**
   - 乱数のバイトを31で割った余りを使うと、文字の出やすさに偏りが出る。`rand.Int` は 0〜30 を均等に返す
   - 組み合わせは 31^8（約8500億）通り。総当たりは、参加の API のレート制限（タスク 5.2）で防ぐ
   - コードがほかの招待と重なったら（ユニーク制約の違反 `23505` を制約名で見分ける）、3回まで作り直す
4. **招待で付与できるのは編集者と閲覧者だけ**（DB の CHECK 制約と、`ParseAssignableRole` の両方で防ぐ。docs/decisions/0012）
5. **有効期限は7日で固定する**（列の初期値）。期限を選べるようにする要件はないため、必要になったら追加する
6. **取り消しは何度呼んでも 204 にし、最初に取り消した日時を保つ**（`COALESCE(revoked_at, now())`）
7. **招待リンクのドメインは環境変数 `INVITE_BASE_URL` で渡し、`serve` でだけ必須にする**
   - 招待用のドメインはまだ決まっていない。`migrate` などのサブコマンドでは要らないため、設定の読み込み（`config.Load`）では必須にせず、形式だけを確かめる
   - 環境変数の名前は `config` だけが知り、app には検証済みの `*url.URL` を渡す
