# 開発ログ（判断の記録）

設計や運用で迷ったこと・決めたことを、「背景・検討した案・決定・理由・トレードオフ」とあわせて1件1ファイルで残す（ADR：Architecture Decision Record の形式）。

- ファイル名：`NNNN-短い題名.md`（番号は連番）
- 状態：`提案` / `採用` / `廃止` / `置き換え（→ NNNN）`
- 一度採用した記録は書き換えず、判断が変わったら新しい記録を追加して、古い記録の状態を「置き換え」にする
